# Byterive

We connect business systems, keep their code healthy, and share the tools we build along the way.

[byterive.com](https://byterive.com) · [Book a 30-minute script review](https://calendly.com/byterive?utm_source=github&utm_medium=profile&utm_campaign=evergreen&utm_content=byterive)

## What we work on

- **NetSuite and SuiteScript.** Customization, fixes and migration of SuiteScript 1.0 and 2.0 to 2.1. We have built or worked on 900+ SuiteScript files across 35+ clients, over 6+ years on NetSuite.
- **Integrations.** Celigo and Boomi integrations, EDI flows (X12 and EDIFACT), CRM sync, and the backend services behind them.
- **Backend and data.** Go, Node.js and Python services, and data research tools.
- **Games.** Unity game tooling for Android.

## Open source: Claude Code plugins

We built these plugins for our own projects and share them through one marketplace, [Byterive kit](https://github.com/Byterive/kit).

| Plugin | What it does |
|---|---|
| [kickoff](https://github.com/Byterive/kickoff) | Starts a project in one command and picks it up again next session |
| [guidebook](https://github.com/Byterive/guidebook) | Turns a project into plain-language guides and refreshes them when the project changes |
| [unity-game-kit](https://github.com/Byterive/unity-game-kit) | Sets up a Unity game the same way every time and tells you what is missing |
| [idea2spec](https://github.com/Byterive/idea2spec) | Tests an idea before you build it, and writes a spec only on GO |
| [cachepulse](https://github.com/Byterive/cachepulse) | Shows whether Claude Code reused its prompt cache, and why not |

Install any of them in Claude Code:

```
/plugin marketplace add Byterive/kit
/plugin install kickoff@byterive-kit
```

Each repository has its own README, privacy page and licence (MIT).
