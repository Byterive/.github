# Security

If you find a security problem in a Byterive repository, please report it privately:

- use **Report a vulnerability** on the repository's Security tab, or
- write to us through the contact form at [byterive.com](https://byterive.com).

Please do not open a public issue for a security problem. Tell us the repository, the version and the steps to reproduce it. We will reply and fix what we confirm.
